## Projects
- **[chess-rating-predictor](https://github.com/EloiGomez/chess-rating-predictor)** — predicts a Lichess rating from 5–15 games using Stockfish-derived features and Gradient Boosting (MAE 168 Elo in blitz, R² 0.89).
- **[RubikLab](https://github.com/EloiGomez/RubikLab)** — browser Rubik's cube simulator with a Kociemba two-phase solver and a group-theory visualiser.
- **[wordle-solver](https://github.com/EloiGomez/wordle-solver)** — suggests the next Wordle guess by maximising expected information (Shannon entropy) weighted by word frequency: 3.9 attempts on average in simulation vs 5.3 for a random candidate. **[Try it online](https://eloigomez.github.io/wordle-solver/)**: play, get suggestions, or solve your own game.
- **[web-attendance-control-students](https://github.com/EloiGomez/web-attendance-control-students)** — school attendance tracker (Google Apps Script) that replaces a multi-tab Excel workbook.

> Most of my projects are built with AI-assisted development (Claude Code): I define the requirements and direct the iteration. The original terminal Wordle solver and my Discord bots are my own code.
